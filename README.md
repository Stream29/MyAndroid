# MyAndroid

Android & HyperOS privacy, ADB utilities, mobile IME notes, and the [`DashVoice/`](https://github.com/Stream29/DashVoice) voice-input client.

- [`bin/hyperos-privacy`](bin/hyperos-privacy): Audits (`check`) or applies (`apply`) HyperOS/MIUI telemetry, ad, and package lockdown rules over ADB.
- [`bin/adb-qr`](bin/adb-qr): Wireless ADB pairing via QR code.
- [`DashVoice/`](DashVoice/): Git submodule for the Android voice-input client (`io.github.stream29.dashvoice`).
- [`docs/root-and-modules.md`](docs/root-and-modules.md): Complete KernelSU root setup, Zygisk/LSPosed modules, Play Integrity/TrickyStore attestation, and proxy checklist.
- [`docs/ime.md`](docs/ime.md): Android Fcitx5 / Rime / Kagiroi / RimeSync + RSAF / DashVoice setup notes.
